# parseuri

Parse URLs and uri query parts with stable normalization.

**Site:** https://theworker02.github.io/parseuri/

## Install / run

```bash
git clone https://github.com/theworker02/parseuri.git
cd parseuri
node src/cli.js
node --test
```
